❓ Frequently Asked Questions (FAQ)

Everything you need to know about setting up and using VehereGo

Q: How does VehereGo turn ordinary notifications into Live Activity capsules?

VehereGo uses an intelligent notification listener with custom regex parsing rules. When enabled, it automatically extracts key data (such as tracking numbers, rider locations, pickup codes, or flight statuses) and displays them as dynamic floating capsules in your status bar.

Q: How does screenshot pickup code extraction work?

When you take or save a screenshot containing parcel pickup codes (e.g. Cainiao, SF Express, Hive Box, Meituan), VehereGo's on-device OCR instantly detects the code, pops up a quick card, and generates a scannable barcode for station pickup.

Q: How do I import PKPass vouchers into VehereGo?

Simply tap any .pkpass file in your file manager, browser, or messaging app and select "Open with VehereGo". The app will parse and save it directly to your digital card wallet.
