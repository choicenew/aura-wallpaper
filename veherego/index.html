❓ Frequently Asked Questions (FAQ)

Everything you need to know about setting up and using VehereGo

Q: How does VehereGo turn ordinary notifications into Live Activity capsules?

English: VehereGo uses an intelligent notification listener with custom regex parsing rules. When enabled, it automatically extracts key data (such as tracking numbers, rider locations, pickup codes, or flight statuses) and displays them as dynamic floating capsules in your status bar.

中文：VehereGo 内置智能通知监听与正则匹配引擎，能把普通系统的通知关键要素（提取码、骑手位置、快递单号）提取出来展现为状态栏灵动岛悬浮胶囊。

Q: How does screenshot pickup code extraction work?

English: When you take or save a screenshot containing parcel pickup codes (e.g. Cainiao, SF Express, Hive Box, Meituan), VehereGo's on-device OCR instantly detects the code, pops up a quick card, and generates a scannable barcode for station pickup.

中文：应用检测到包含取件码的截图时，会通过端侧离线 OCR 秒级抓取，弹窗并生成条形码供快件驿站或柜机扫码取件。

Q: How do I import PKPass vouchers into VehereGo?

English: Simply tap any .pkpass file in your file manager, browser, or messaging app and select "Open with VehereGo". The app will parse and save it directly to your digital card wallet.

中文：在文件管理器或聊天软件中点击任何 .pkpass 文件并选择使用 VehereGo 打开，即可自动将卡券加入您的数字卡包。
